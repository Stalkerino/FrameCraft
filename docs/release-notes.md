Download the desktop app below (do not use the GitHub source-code ZIP to install):

- **Windows x64:** run the `-setup.exe` installer, then open Framecraft from Start.
- **Linux x64:** make the `.AppImage` executable and run it, or install the `.deb` with your package manager. Ubuntu 22.04+ and compatible glibc distributions are the build baseline.

Node, the backend, native media libraries and built-in assets are bundled. No Node, Rust or Chrome installation is required to open the editor. The Windows installer supplies WebView2 if missing. AI providers are optional; configure your own CLI or Ollama server inside the app. Projects and settings are stored outside the installation and preserved across updates.

SHA-256 checksums are included. Builds are currently unsigned. [Installation details](https://github.com/Stalkerino/FrameCraft/blob/main/docs/installation.md).
